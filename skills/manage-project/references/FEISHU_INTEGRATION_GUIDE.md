# 项目管理技能飞书对接规范
## 一、LAB知识库公共协作区固定资源清单
所有操作必须先检查以下已存在的固定资源，禁止重复创建同名资源：
| 资源名称 | 资源类型 | 用途说明 | 操作权限 |
|---------|---------|---------|---------|
| 【公开项目】 | 文档（Doc） | 统一存储所有项目的基础信息列表 | 追加内容，除非明确指定，否则禁止覆盖/删除原有内容 |
| 甘特图 | 多维表格（Base） | 所有项目甘特图节点存储和进度管理 | 新增/更新行，禁止修改表格结构 |
| 紧急项目甘特图 | 多维表格（Base） | 高优先级项目专项跟踪表 | 新增/更新行，禁止修改表格结构 |
| 项目信息 | 文档（Doc） | 项目基础信息总表 | 新增/更新行，禁止修改表格结构 |
## 二、不同操作类型对应资源规范对照表
执行任何写入操作前必须对照下表，选择正确的资源类型和操作方式：
| 操作场景 | 目标资源 | 资源类型 | 操作要求 | 禁止行为 |
|---------|---------|---------|---------|---------|
| 新建项目时写入项目列表 | 【公开项目】文档 | 已有文档 | 在文档末尾追加新项目信息块 | 新创建同名文档、覆盖原有内容 |
| 新建项目时创建项目专属资料 | {项目名}-项目说明书 | 新建文档 | 在公共协作区根目录创建 | 存储到其他目录、使用非标准命名 |
| 新建项目时写入甘特图节点 | 甘特图多维表格 | 已有表格 | 新增对应项目的行记录 | 新创建甘特图表格、修改已有项目的原有节点结构 |
| 标记高优先级项目 | high_priority_projects多维表格 | 已有表格 | 新增对应项目的行记录 | 新创建高优先级跟踪表格 |
| 项目进度更新 | 甘特图多维表格、项目专属说明书 | 已有资源 | 更新对应节点状态、追加进度记录 | 创建新文档记录进度、修改其他项目的内容 |
| 生成每周进度报告 | {YYYY-MM-DD}-项目进度周报 | 新建文档 | 在公共协作区「周报」目录创建 | 存储到根目录、使用非标准日期命名 |
| 高优先级项目进度表存储 | {项目名}-高优先级跟踪表 | 新建多维表格 | 在公共协作区「高优先级项目」目录创建 | 存储到根目录、与普通项目文档混放 |
## 三、操作前检查流程
每次执行飞书写入操作前必须按以下步骤检查：
1. **资源存在性检查**：先调用`cos_doc（action=list）`接口查询目标资源是否已存在
2. **类型匹配检查**：确认资源类型与操作要求一致（文档/多维表格不能混用）
3. **权限检查**：确认当前操作对目标资源只有允许的操作权限
4. **重复内容检查**：对于已有资源，检查是否已有相同项目的内容，避免重复追加
## 四、异常降级规则
- 检查发现资源不存在：先判断是否为固定资源，固定资源缺失则终止操作并提示"请先配置LAB知识库固定资源"
- 资源类型不匹配：终止操作并提示"目标资源类型与操作要求不符，请检查配置"
- 操作权限不足：终止操作并提示"当前操作无对应资源的操作权限"
