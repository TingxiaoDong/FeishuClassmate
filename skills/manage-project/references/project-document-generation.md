# 项目文档生成指南

## 前置准备
调用 `feishu_classmate_data_layout()` 获取配置：
- 所有项目资源默认写入飞书【Lab知识库】公共协作区
- 项目列表统一维护在【公开项目】文档

## 从文档创建项目
### 生成项目文档
1. 接收用户上传的项目文档，调用 `cos_doc（action=get）` 解析内容
2. 提取核心信息：名称、负责人、起止时间、任务节点、预期产出
3. 在【Lab知识库】公共协作区，生成项目专属文档，包含：状态、简介、目标、进展、待办、计划
4. 发送文档草稿给用户确认修改，确认前不写入任何表格

## 从自然语言创建项目
### 生成项目文档
1. 收到项目创建请求，调用 `普通对话提问（等待用户下一条消息）` 收集核心信息：项目名、负责人、起止时间、主要任务节点
2. 生成项目专属文档草稿，包含：状态、简介、目标、进展、待办、计划
3. 发送文档草稿给用户确认修改，确认前不写入任何表格
