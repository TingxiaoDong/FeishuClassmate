# ClassmateOS 前端接口核查（2026-10-20）

> 范围：`classmateos/app/lib`（Flutter 前端，不含 `mock/`）与 `classmateos/server`（后端路由、`CAPABILITIES` 功能开关）。
> 方式：静态比对前端所有接口调用与后端注册的路由，再逐项核对页面入口受哪个功能开关控制。
> 本次按要求**只检查、出文档，未修改代码**；没有启动后端，也没有在 App 里逐页点击验证。

## 1. 总体结论

| 项 | 情况 |
|---|---|
| Mock 是否混入正式模式 | **没有**。`mock/` 只在 `main.dart` 引用，仅当 `COS_MOCK=1` 时用 `MockBackend` 替换 HTTP 客户端；正式模式所有页面都走真实接口层，没有页面内写死的假数据。 |
| 前端接口调用 | 约 180 处调用、170 个不同接口；与后端路由对上约 130 个。 |
| 后端缺失的接口 | **约 45 个**，集中在：扫码登录、知识库、文件夹 / 回收站 / 收藏、表权限与表管理、记录评论、导入导出、成员批量导入、工作台应用（见第 3 节）。 |
| 后端已做、但前端没接通 | **3 处**，都是功能开关问题，不是接口没写（见第 2 节）。 |
| “Mock 才能看到”的功能 | 后端没做的功能，前端入口因开关为 false 自动隐藏，正式模式下看不到，只能在 `COS_MOCK=1` 下体验。 |

## 2. 后端已做、前端没接通（建议优先处理）

| # | 功能 | 现状 | 原因 | 建议改法 |
|---|---|---|---|---|
| 1 | 记录修改历史 | 后端 `GET /tables/:key/records/:id/history` 已有，开关 `record.history: true` | 前端记录详情右侧「评论 / 修改记录」面板只看 `record.comments`（`pages/bitable_field.dart:422`、`:572`），而后端该开关不存在（=false），所以历史面板整个不显示 | 前端改为 `record.history` 或 `record.comments` 任一开启就显示面板；只开 history 时隐藏评论输入框 |
| 2 | 管理后台（成员、角色、操作日志、安全设置） | 后端 `/users`（含 `include=admin`、部门 / 状态筛选）、`/users/:id/reset-password`、`/users/:id/logout-all`、`/roles*`、`/audit-logs`、`/audit-logs/exports`、`/admin/security-settings` 都已实现并做了权限校验 | `CAPABILITIES.admin = false`，前端 `canAdmin` 要求开关为 true（`app_state.dart:97`），入口隐藏 | 后端打开 `admin`；成员批量导入单独由 `user.import` 控制（仍未做），不影响其他页 |
| 3 | 组织架构、通讯录按部门浏览、名片部门路径 | 后端 `routes-departments.ts` 已实现部门增删改查、路径、成员增删 | `CAPABILITIES` 里没有 `org.departments`，前端（`contacts_page.dart:106/321`、`admin_page.dart:45/225`）全部隐藏 | 后端加 `'org.departments': true` |

以上三项打开后需要按《二期前端开发进度总览》第 10 节的方式补一轮真实后端联调（`live_backend_test.dart` 增加对应用例）。

另有 2 处“接口在、但参数没实现”：

| 功能 | 问题 |
|---|---|
| 报表时间范围（`dashboard.range`） | `GET /dashboard/summary` 存在，但不读 `range / start_at / end_at`，始终返回全部数据；开关也没开。需后端支持范围参数后再打开开关。 |
| 文档列表 `GET /docs` | 只支持 `scope = mine / shared`（其他值按全部处理），不支持前端用到的 `recent / starred / trash` 和 `folder_id`、`permanent=true` 删除。属于 `doc.folders` 未做的一部分。 |

## 4. 后端有、前端暂未使用的接口（无需处理，供参考）

都不是“该接没接”：`GET /calendar/events/:id`、`GET /devices`、`GET /jobs`、`GET /tables/:key/records/:id`、`GET /tasklists/:id/tasks`、`GET /users/:id/avatar`（前端直接拼头像地址）等前端暂时用不到；话题关注、收藏、固定消息、任务关注人、文档评论 / 版本列表等前端其实已经调用，只是写法是三元表达式或分页封装，静态比对脚本没识别出来，已人工确认。
