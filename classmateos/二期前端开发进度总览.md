## 2. 后端需要提供的功能开关

前端启动时、WS 重连后、收到 `capabilities.changed` 时调用 `GET /api/v1/capabilities`。**某个开关缺失或为 false，对应入口整块隐藏，一期功能照常可用**；接口返回 404 时只开放一期功能和新建表。后端某块做好就打开对应开关，可以分批上线。

| 开关 | 控制的功能 | 迭代 |
|---|---|---|
| `table.create` | 新建数据表（已上线） | 一期补充 |
| `table.fields` | 字段新增 / 编辑 / 删除 / 排序、类型转换预览 | 1 |
| `table.views` | 保存视图（筛选、排序、分组、隐藏列、个人视图） | 1 |
| `notifications` | 通知中心铃铛、通知设置 | 1 |
| `table.permissions` | 表权限设置 | 2 |
| `table.manage` | 表重命名 / 描述、复制、删除 | 2 |
| `record.comments` | 记录评论、修改记录 | 2 |
| `doc.permissions` | 文档分享面板、申请权限 | 2 |
| `doc.comments` | 文档评论 | 2 |
| `doc.versions` | 历史版本 | 2 |
| `doc.folders` | 我的空间 / 共享给我 / 收藏 / 回收站、文件夹 | 2 |
| `doc.presence` | 协同在线头像（前端新增的开关，见迭代 2 文档 3.6） | 2 |
| `wiki` | 知识库模块 | 2 |
| `calendar.recurrence` | 重复日程；开启后日程列表改用 `start_ms / end_ms` 参数 | 3 |
| `task.subtasks` | 子任务 | 3 |
| `task.followers` | 关注人、「我关注的」（前端新增的开关） | 3 |
| `task.comments` | 任务评论和动态（前端新增的开关） | 3 |
| `task.lists` | 任务清单、分组、成员（前端新增的开关） | 3 |

功能开关只控制入口显隐，**不能代替权限校验**，后端每个接口仍需校验并返回 403 + 中文 `message`。

## 3. 需求文档之外、前端额外约定的接口和字段（请后端重点看）

需求文档没写、或前端按自己理解实现的地方，后端适配时最容易漏。完整说明见各迭代文档的对应章节。

| # | 约定 | 位置 |
|---|---|---|
| 1 | 新增 `GET /tables/:key`（取单张表） | 迭代 1 文档 第 3 节 |
| 2 | 选项改名时请求里带 `option_renames`（旧选项 → 新选项），后端据此迁移记录值 | 迭代 1 文档 3.1 |
| 3 | 记录变更事件必须带 `operator_id`；记录类通知的 `target` 带 `table_key` | 迭代 1 文档 3.6、3.7 |
| 4 | 筛选条件值的格式、视图排序接口字段名按前端实现 | 迭代 1 文档 3.2 |
| 5 | 设备注册只接受 ios / android；macOS 要推送需后端放开 | 迭代 1 文档 3.8 |
| 6 | 文档对象带 `wiki_space_id`、`wiki_node_id`；`GET /docs?scope=mine` 不带 `folder_id` 时只返回根目录 | 迭代 2 文档 3.1 |
| 7 | WS 事件 `doc.permission_changed`、`wiki.space_changed` | 迭代 2 文档 3.1、3.5 |
| 8 | 文档评论锚点暂用 `{offset, length}` + `quote`，后端原样保存，不校验格式 | 迭代 2 文档 3.2 |

| 13 | 删除分组时任务移到未分组；删除清单只解除关联，不删任务 | 迭代 3 文档 4.5 |

## 4. 需要后端拍板的问题

| 问题 | 前端现在的做法 |
|---|---|
| 删除父任务时子任务怎么处理 | 模拟后端是一起删除；前端提示文字未写死 |
| 知识空间删除后页面进回收站还是直接删 | 前端提示「无法恢复」 |
| 文档权限申请的通知 `target` 格式 | 先按 `{type: "access_request", doc_id, request_id}`；一键同意按钮等格式定了再做 |
| 重复日程 `following / all` 修改时间的含义、时区（建议日程加 `timezone`） | 前端传当前实例的新时间，由后端计算偏移 |
| 协同 WS 是否允许只读用户连接（只转发 awareness） | 确认后再打开 `doc.presence` |
